# MASTER_PLAN.md — AIVJ 最終組織・基本方針

状態: STEP 1 承認済み（2026-11-02、社長。以後の修正は同じファイルを更新。最終更新 2026-11-02）／基準資料: 「AIVJ AI 組織運営体制・構築実行計画 統合改訂版」(2026-10-25)

## 1. 目的
社長1名・業務委託4名・AI役割59・外部パートナーで、営業→提案→受注→制作/運用→納品→請求→継続提案までを回す。
人間は商談・判断・例外調整・最終確認に集中し、定型業務は AI が分担する。

## 2. 大前提（最優先）
1. ゼロから構築し、旧システム・旧DB・旧ワークフローは流用・連携しない。Claude アカウントは会社メールで作成済みの現アカウントを使用する（D-008）。
2. 59は「役割数」。実行エージェント数とは一致しない（1実行体が複数役割を兼務可）。AI は法的な役員・従業員ではない。
3. 契約・支出・重要な対外送信・本番反映・権限変更は人間が承認する。
4. AI COO は AI 業務を統括するが、業務委託人材への契約上の指示権・決裁権を持たない。
5. 成果（AI検索での推薦増加など）は保証しない。測定値・推計値・不明点を区別し、データ・出典を捏造しない。

## 3. 二層構造
- 縦軸（機能別7部）: 営業 / 事業開発 / AIV・調査分析 / AIO・デジタルマーケティング / 事業推進 / 経営管理 / AIシステム
- 横軸（サービス別責任）: 売上・原価・品質・顧客成果を管理。既存の部長 AI が兼任し、新たな役割・部は増やさない。
- 個別案件の工程管理は事業推進部、優先順位調整は AI COO。

### 組織規模
| 項目 | 数 |
|---|---|
| 部 | 7 |
| 課（論理単位・専任課長 AI なし） | 25 |
| 係 | 51 |
| AI 役割 | 59 = COO 1 + 部長 7 + 係担当 51 |
| 人間 | 社長 1 + 業務委託 4（営業 / 事業開発・品質 / 経営管理・総務 / PM・外注管理） |

詳細な一覧は `AI_ROLES.csv`（部・課・係・役割・リスク区分・段階・フォルダ）を正とする。
実装状態の値: `not_implemented`（未着手）／`definition_drafted`（role.yaml の定義案あり・未承認）／`implemented`（実装・検証済み）。

## 4. サービス責任マップ
| サービス区分 | 責任者（AI 役割が兼務） | 補足 |
|---|---|---|
| AIV・AI需要／市場分析 | AIV・調査分析部長 AI | 品質は経営管理部が独立監査 |
| AIO 改善・実装 | AIO・デジマ部長 AI | AIV 部が効果を独立再測定 |
| SEO・MEO・広告・SNS 等 | AIO・デジマ部長 AI | 営業部と連携 |
| Web 制作・観光戦略等（外注統括） | 事業推進部長 AI | 外注先は PM 担当が折衝 |
| データ分析・測定（承認済み 2026-11-02） | AIV・調査分析部長 AI | 資料に責任者の明記なし |
| プロモーション制作・旅行商品・海外誘客（承認済み 2026-11-02） | 事業推進部長 AI | 資料の「Web 制作・観光戦略等」に含まれる想定 |

## 5. 人間の配置と判断範囲
| 人間 | 主な判断／対人業務 |
|---|---|
| 社長 | 経営方針、重要商談、契約・発注・支出の決裁、緊急停止 |
| 営業担当（委託） | 商談・提案説明・条件調整 |
| 事業開発・品質担当（委託） | 新商品の実用性評価、重要分析のレビュー（自身の開発案件は独立専門家が再審査） |
| 経営管理・総務担当（委託） | 請求・入金・契約・証憑確認、例外事務 |
| PM・外注管理担当（委託） | 外注先折衝、仕様・納期調整、顧客検収窓口 |
| 外部技術顧問・弁護士・税理士等 | 設計審査・重大障害・専門判断（上記5名に含めない） |

## 6. 責任の流れ
事業開発[商品化確認] → 営業[人間の商談] → 事業推進[案件PM] → AIV[測定・報告]／AIO・デジマ[改善・運用] → 独立監査[品質] → 納品・請求 → サービス責任者による継続改善

## 7. 内製／外注の原則
- 内製: データ分析、AIV・AIO、自然検索SEO、広告・SNS・GBPの遠隔運用（顧客の権限・同意の範囲内）
- 外注: 対面支援、観光戦略、Web本格制作、撮影・編集、現地実務
- AIO と SEO の共通改修は単一バックログで管理。実際の技術改修は外注先と連携。
