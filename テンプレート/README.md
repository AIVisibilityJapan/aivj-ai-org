# テンプレート/

提案書・見積・レポート・契約書草案・メール文面の雛形。契約書草案は専門家確認前に使用しない。
顧客固有の情報・実案件の成果物は Git に置かず、Supabase（Storage／DB）で管理する。

## フォルダ構成（2026-11-04 作成、D-031）
| フォルダ | 内容 |
|---|---|
| 01-営業資料 | 会社紹介・サービス紹介などの雛形 |
| 02-レポート | AIV・AIO 診断レポートなどの雛形 |
| 03-提案書 | 提案書・企画書・応募書類の雛形 |
| 04-見積 | 見積書・請求書の雛形 |
| 05-メール文面 | 営業・フォロー等の文面の雛形 |
| 06-契約書草案 | 契約書の草案（専門家確認前は使用しない） |

顧客名の入ったもの・実案件の成果物は `データ/private/`（Git に載せない）へ。
