# データ/

- fixtures/: 試験用の架空データのみ（例: ダミー自治体サイト一覧.csv。URL は example.invalid で実在しない）。
- 実顧客データ・個人情報は置かない（`データ/private/` は .gitignore 済み。顧客データは Supabase で管理）。
- private/（Git に載せない）: 01-顧客別（管理番号フォルダ）、02-受領資料、03-実案件の成果物。バックアップは各自で取る（2-9 で手順化）。
- 測定データ参照.md: APA・出現率の測定データの置き場所・版数・SHA の記録（データ本体はコピーしない）。
- 実行状態/（Git に載せない）: タスク・承認・停止ログなど実行時の状態。
- private/一時保存/: 手持ち資料の仮置き場。Claude が内容を確認して各保存先へ振り分ける（コピー。元は残る）。
- private/04-自社資料/: 自社の完成資料・見本・営業資料（大容量・第三者の名前を含むもの）。
