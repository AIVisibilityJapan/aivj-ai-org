# 資源確認：住所（所在地）の監査ルール

状態: 標準ルール（2026-11-10 社長指示「資源は該当する自治体に属するか、必ず住所は監査するようにする」）
対象: 無償診断レポートの観光資源（3枠）に追加・紐付けするすべての資源

## 1. 原則
- 資源を自治体に追加・紐付けする前に、**その資源の所在地が該当自治体に属するか**を、必ず独立監査で確認する。
- 監査は、証拠収集を行った担当とは別の担当（独立監査）が行う。収集した担当の自己確認では通さない。
- 所在地を確認できない資源は、追加しない（枠は「―」のままでよい。3枠を埋める必要はない）。

## 2. 証拠として記録するもの（1資源ごと）
| 項目 | 内容 |
|---|---|
| 資源名 | 出現率データ・APA上の表記と、公式の正式名称 |
| 住所の原文 | 公式サイトからの住所の抜粋（市区町村名を含む）。引用元URL、取得日 |
| 所在市区町村 | 住所の市区町村名が、対象自治体と一致するか |
| 現在の運営状況 | 営業・公開が現在も続いているか。根拠の日付つき |
| 市境・広域資源 | 河川・湖・山・海岸・遺跡など、複数の自治体にまたがる可能性があるか |
| 根拠の種類 | 公式（自治体・施設・管理者）／準公式／その他。その他のみの場合は「参考候補」 |

## 3. 判定
| 結果 | 条件 | 扱い |
|---|---|---|
| 追加可 | 公式の住所が対象自治体内にあり、現在の運営が確認できる | 独立監査を経て、社長確認① |
| 要確認 | 市境にまたがる、住所の根拠が公式でない、現在の運営の根拠が古い | 追加しない。追加の調査の後に再監査 |
| 追加不可 | 所在地が別の自治体、または同名の施設が確認できない | 追加しない |

- 資源名に自治体名や地域名が含まれていても（例:「和泉温泉」「和泉葛城山温泉」）、所在地は住所で確認する。名前だけで帰属を判断しない。
- 地名が自治体の境界にまたがる場合（例: 光明池）は、対象自治体に属する範囲を確認できるまで「要確認」とする。

## 4. 運用
- 独立監査（AI-06-05）は、証拠一覧の住所の原文を見て判定する。原文のない証拠は判定しない。
- 判定結果と根拠は、判断ログ・承認ログに残す。
- このルールは、資源追記ツール（設計: 文書/設計/資源追記ツール設計_20261109.md）の仕様（監査参照・社長確認の参照）にも反映する。
