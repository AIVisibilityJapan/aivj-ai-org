# 権限の絞り方（実行状態・private を社長だけが読めるようにする）

対象: `データ\実行状態\`（管理画面.html、費用集計.csv、承認・停止の記録）と `データ\private\`（顧客別・受領資料・自社資料）。
目的: 同じ PC を使う他のアカウントや、共有フォルダ経由で第三者が見られないようにする（D-034）。
Git には元から載りません（.gitignore）。ここでは PC 内の閲覧者を絞ります。

## 手順（1 回だけ。PowerShell を社長のアカウントで開いて実行）
```powershell
cd C:\dev\aivj-ai-org
New-Item -ItemType Directory -Force データ\実行状態 | Out-Null
icacls データ\実行状態 /inheritance:r /grant:r "${env:USERNAME}:(OI)(CI)F" "SYSTEM:(OI)(CI)F"
icacls データ\private  /inheritance:r /grant:r "${env:USERNAME}:(OI)(CI)F" "SYSTEM:(OI)(CI)F"
```
- 社長のアカウントと SYSTEM（Windows 自身）以外の権限を外します。管理者アカウントは、権限を取り直せば開けるため、完全な遮断ではありません。
- 実行後、次で確認します。表示されるのが社長のアカウントと SYSTEM だけならよいです。
```powershell
icacls データ\実行状態
icacls データ\private
```

## 元に戻す
```powershell
icacls データ\実行状態 /reset /T
```

## 併せて守ること
- C:\dev\aivj-ai-org を OneDrive・Google ドライブ等の同期フォルダの中に置かない（置いてあると、権限を絞っても同期先へ出ます）。
- 管理画面.html・費用集計.csv をメール添付・チャット・共有フォルダに置かない。
- 画面共有で見せるときは、見せる相手を確認してから。
- バックアップは、暗号化されたドライブか、本人しか開けない場所に置く（2-9 で手順を確認）。
