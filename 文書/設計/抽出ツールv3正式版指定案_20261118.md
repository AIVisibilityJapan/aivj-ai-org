前提: v2 の指定（`抽出ツール正式版指定_20261114.md`）はそのまま残す。v2 は rollback 用に保持し、上書き・削除しない。

## 指定（案）
- 正式版: `scripts/aiv_extract_candidates_one_v3.py`
- rollback 用（保持）: `scripts/aiv_extract_candidates_one_v2.py`（その前の rollback は v1）

## v2 → v3 の変更点
- 入力（Gate 表・selector スロット・master・alias・relation）を、固定の「入力」フォルダではなく、`--formal-root` の現行ポインタから解決する。版名の直書きをやめた。
- pointer と pin の SHA 不一致、キー欠落、ファイル欠落は停止する。入力が実行中に変わったら失敗にする。
- `08_summary.json` に、読んだ各ファイルの版・パス・SHA256 を記録する。
- 出力フォルダ名は、同じ秒に 2 回実行しても衝突しない（_2, _3 …）。
- 候補を抽出する処理（00〜07 の出力）は v2 と同じ。

使い方: `py scripts\aiv_extract_candidates_one_v3.py --formal-root "<...\AI Visibility>" 自治体名 都道府県`（解決結果だけを見るときは `--show-resolved`）。
