# Gate 更新 社長確認依頼（2026-11-14）

結論：和泉市の無償レポートを作れる状態にするため、Resource Preflight Gate 1.1.9（source contract 1.1.10）への current pointer の切替（確認②）の承認をお願いします。新版は stage 作成と実ファイル検証まで完了しており、正式データ（現行 pointer・Gate・アダプタ）は一切変更していません。

## 0. 用語：「解除」とは
Gate が自治体ごとに持つ「レポートを作ってよいか」の判定のうち、和泉市の「ブロック」を外すことです。判定表の和泉市の1行を「確認が終わった」状態（未レビュー候補4→0、判定をブロック→通過、生成可否 FALSE→TRUE）に書き換えます。レポートの内容や、観光資源の確認結果を変えるものではありません。判定表はハッシュで固定されているため、1行の書き換えにも、新しい Gate 版の発行と pointer の切替（正式データの変更）が必要で、そのため承認をお願いしています。

## 1. 背景（1分で読む部分）
- Gate は、自治体ごとの判定表の1項目（preflight_result）だけで、レポート生成の可否を決めています。和泉市は「観光資源の候補が未レビュー」としてブロック中です（候補数は high 4／medium 29／low 67、未レビュー4）。
- 和泉市の観光資源は、住所を監査し、測定で出た固有名詞と照合して、確認を終えました（採用5・今回不使用5・不採用19・要確認0）。
- Gate は、判定表・契約・pointer・スクリプトを、ハッシュ（SHA-256）で固定しています。判定表の1行を変えるには、これらを連鎖して作り直す必要があり、新しい Gate 版の発行になります。
