# 観光資源の原文再監査・正式採用・マスター反映フロー 取込メモ

受領: 2026-11-05（社長が共有。「現行運用説明」）。原文: データ/private/05-測定データ/観光資源_原文再監査フロー_原文.txt（原文は編集しない。Git に載せない）。**原文が正本。本メモは要点の整理で、食い違いがあれば原文を優先して本メモを直す。**

## 1. 要点
- 無償レポートの『出現を支える観光資源 Top3』は、**測定内に実際にある資源だけ**を、identity・自治体との関係・現役性・出どころ（source lineage）まで確認して表示する。3 枠を埋めることが目的ではない。「―」は正式な診断結果になり得る（3 件未満＝失敗ではない）。
- 取得順（source priority）: ① Appearance 1〜3 位 → ② APA 正式資源 → ③ Appearance 4〜5 位 → ④「―」。混ぜて再ランキングしない。
- Top3 が足りないときは、すぐ「―」にせず、**原文まで遡る**（Appearance の rank1〜5・出現証跡、APA の自治体自身の WIN 推薦理由原文）。
- 原文から具体名の候補を抽出しても、**候補抽出＝正式採用ではない**。一般表現（「温泉」「道の駅」など）は採用しない。推測・近隣からの補完・外部サイトの検索による追加は禁止。
- 公式情報は『測定原文にあった候補が本当にその資源か』を確かめる Evidence として使う（測定由来の候補＋公式 Evidence の両方が必要）。
- 分類は 12 種（SELF_VERIFIED_ACTIVE／…／REVIEW_REQUIRED／REJECTED）で未分類を残さない。判断不能は REVIEW_REQUIRED として保留し、レポートに出さない。
- **レポート（PPTX）に直接書き足さない。** 正式経路: 測定原文 → candidate → Evidence Review → Common Asset／Alias → resource mention → APA mapping → Diagnostic selector → 無償レポート。
- 更新は append-only（上書きしない）。selector の次版を作り、**全国回帰**（1,741 自治体・5,223 枠すべて PASS、想定外の差分 0 など）と Resource Preflight Gate の再判定を通してから、current pointer を切り替える。旧版は rollback 用に残す。Appearance の測定値・APA の順位は資源の整理を理由に再計算しない。
- 生成後 QA（placeholder 0・selector／Appearance／APA／競合／ネガティブの不一致 0）、Visual QA（全ページ。切れ・重なり・overflow・誤った「―」）、PDF は **PowerPoint 標準の PDF 書き出し**（別のレンダラーは正式成果物に使わない）。
- source contract／SHA が合わないときは RESOURCE_COVERAGE_SOURCE_ERROR で止まる（silent fallback 禁止）。

## 3. 責任の境界（本組織の AI ができること・できないこと）
- このフロー（原文遡り・Evidence Review・Common Asset／Alias／mapping／selector の更新・全国回帰・pointer 切替）は、**マスターを作る上流の工程**。本組織の AI-03-01 は、その結果（正式データ）を読み取るだけで、この工程は行わない（D-040。補完・再計算は禁止）。
- AI-03-05 は、selector の正式出力と完全一致するように差し込む。自分で資源を選ばない（原文 §30 と一致）。
- 上流工程の実施者と、それを本組織の役割として持つかは未決（§5）。
