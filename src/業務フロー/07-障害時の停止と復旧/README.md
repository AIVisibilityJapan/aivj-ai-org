# 異常・障害時の停止と復旧

**目的**: 異常検知から停止・復旧判断まで
**実装段階**: STEP 2（基盤）で最小実装

## 参加する AI 役割
- AI-07-03 システム運用 AI
- AI-07-06 セキュリティ監査 AI
- AI COO

## 人間チェックポイント
- 外部技術顧問: 重大事案の診断
- 社長: 停止／復旧の判断（不在時の代行者は契約で事前設定）

## 工程
1. 稼働監視が異常（予算超過・無限ループ・権限逸脱・品質 NG）を検知
2. 当該エージェントを自動停止
3. AI COO と社長の共有キューへ通知（障害ログ・切り戻し案を添付）
4. 【人間】重大事案は外部技術顧問が診断
5. 【人間】社長が停止／復旧を判断
6. 復旧後に原因と再発防止を 文書/判断ログ へ記録

## 備考
- 手順書は 文書/手順書/ に作成する
