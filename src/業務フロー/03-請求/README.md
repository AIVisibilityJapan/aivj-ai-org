# 検収〜請求・入金

**目的**: 形式検査から請求・入金照合まで
**実装段階**: STEP 6

## 参加する AI 役割
- AI-06-01 請求管理 AI
- AI-06-02 管理会計 AI

## 人間チェックポイント
- PM 担当: 顧客検収窓口
- 経営管理・総務担当: 金額・証憑の照合、支払例外の確認

## 工程
1. 検収後に AI が形式検査・請求書案を作成
2. 【人間】総務担当が金額・証憑を照合
3. 請求 → 入金照合（AI）
4. 入金遅延・相違は総務担当へ例外送付
