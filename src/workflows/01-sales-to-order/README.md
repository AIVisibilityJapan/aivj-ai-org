# 営業・提案〜受注

**目的**: 案件登録から提案・商談・受注までを接続する
**実装段階**: STEP 6

## 参加する AI 役割
- AI-01-03 営業実行 AI
- AI-01-05 企画立案 AI
- AI-01-06 提案資料制作 AI

## 人間チェックポイント
- 営業担当（委託）: 商談・ヒアリング・説明
- 社長: 重要条件（価格・契約条件）の承認

## 工程
1. 営業 AI が案件を登録（案件 ID を発番）
2. 提案・見積・営業資料の草案を AI が作成
3. 【人間】営業担当が商談・質疑・条件調整
4. 【人間】社長が重要条件を承認
5. 受注登録 → 02 納品フローへ

## 備考
- 顧客への確約・値引き・契約条件変更は社長承認
- 営業メールは適法性・配信停止・重複排除を管理

※ 担当・入力・成果物・期限・引継先・失敗時の再実行条件は、実装時に `workflow.yaml` として定義する。
