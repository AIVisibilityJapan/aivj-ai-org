# 受注〜制作・運用〜納品

**目的**: 受注後の工程設計から品質検査・納品調整まで
**実装段階**: STEP 4（AIV/AIO）以降

## 参加する AI 役割
- AI-05-01 PMO 管理 AI
- AI-05-04 外注管理 AI
- 各内製実務 AI（サービスにより異なる）
- AI-06-06 品質・リスク監査 AI

## 人間チェックポイント
- PM・外注管理担当: 外注先との仕様／納期調整・顧客検収窓口
- 事業開発・品質担当: 重要納品物の確認
- 社長: 納品前の決裁

## 工程
1. 受注後に AI が工程案・仕様書草案を作成
2. 【人間】PM 担当が外注先と調整（新規発注は社長承認）
3. 内製 AI／外注先が遂行
4. 独立 AI（経営管理部）＋品質担当が検査
5. 【人間】社長決裁
6. 【人間】PM 担当が納品調整

## 備考
- 分析部門のセルフチェックと独立監査を分離
- 成果物の根拠・数値・契約仕様との一致を別 AI でチェック

※ 担当・入力・成果物・期限・引継先・失敗時の再実行条件は、実装時に `workflow.yaml` として定義する。
