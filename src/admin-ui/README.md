# admin-ui/

管理画面（STEP 2 / 2-7）。実行状態を読み取って 1 枚の HTML を作る、**表示専用**の画面（D-032）。

```
python src/admin-ui/build_dashboard.py      → データ/実行状態/管理画面.html（ブラウザで開く）
```

- 表示: 全体サマリ／案件／要対応・進行中のタスク／承認待ち／人間キュー／停止ログ／承認記録／上限の設定状況／未送信の通知
- 承認・停止・再開はここではできない（チャット、または scripts/stop_control.py）。
- 外部へ送らない。HTML は script・リンク・外部読み込みなし（CSP で禁止）。依頼の中身・実行結果は表示しない。
- 読めないデータと、未設定の上限（起動しない項目）を画面に明示する。
- 顧客名は伏せない。代わりに、フォルダの権限を社長のアカウントだけに絞る（文書/手順書/権限の絞り方.md、D-034）。業務委託者には見せない。外部（Notion 等）へも同期しない。
- 試験: tests/unit/test_admin_ui.py
